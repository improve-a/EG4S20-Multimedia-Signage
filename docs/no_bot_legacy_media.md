所有 BMP 均为 DIB40、planes=1、24bit BI_RGB、BGR 字节、正高度480（文件底向上）。像素偏移固定512；54..511共458字节全部为零；UI 行距1920，PN 行距960，无行填充。`bfSize` 是实际文件大小，无其他资源头或尾巴。

第11个媒体文件 `07_MUSIC.WAV` 为原80秒、单声道 PCM16、48000Hz 文件，7680044字节。SHA256 为 `c0671b035fdd04465ae6280427bbd5732e065693dd066a511a74e9426e818886`；字节原样保留。音频不是第11张图，BMP 目录扫描目标为10。

SDRAM接口配置为21bit字地址×32bit数据，配置地址窗口为2097152字/8388608字节（8MiB）；这描述地址窗口，不以此猜测封装内存的物理密度。像素存储为 `RRGGBB00`。BUF0基址0、范围word0..307199，BUF1基址307200、范围word307200..614399；每帧307200字/1228800字节，两缓存共2457600字节，整体范围word0..614399，无重叠。六页和四面板从TF按需加载，不常驻六页或面板缓存。加载器向后台缓存输出完整640×480顺序像素流，继承 `WRITE_V_FLIP=1` 抵消BMP底向上的文件顺序。

片内逻辑存储另计：loader行RAM640×24bit=1920字节，sector缓存512×8bit=512字节；转场行RAM1024×24bit=3072字节，其中仅索引0..639的640项用于画面，其余为防越界填充。当前 `audio_media` 未覆盖默认参数 `FIFO_ADDRESS_BITS=11`，其 `audio_async_fifo` 容量为2048个32bit PCM帧=8192字节，预填阈值 `PREFILL_FRAMES=512`（2048字节）。单声道源在parser后复制为左右16bit，FIFO仍按32bit帧存储。上述是源码逻辑容量；004综合实际使用BRAM9K 53/64、BRAM32K 5/16；该总数也包括厂商IP与其他模块。

双图由两份独立 PN 文件在运行时逐行合成。猎鹰页为 PN01+PN02，凤凰页反序；精灵页为 PN03+PN04，飞龙页反序；品牌/生态页默认 PN01+PN02。没有用一张预拼双图替代运行时双源。

控制顺序为：锁存候选页/倍率/焦点和后台缓存 → 请求遮罩 → 等cover ACK → 加载 → 同时等源像素完成与SDRAM write_finish → 请求帧提交 → 等读端commit ACK → 保持全遮罩完成新front资格帧 → reveal → 接受下一次实际加载。旧读端ACK不代表预填完成：ACK后的首个帧边界只arm，整个新front帧继续被遮罩；该完整资格帧未出现sticky FIFO fault，才在下一个帧边界开始揭示。缓存索引只用0/1；旧 front 只在 commit ACK 后释放。忙时按键更新最后目标，正在加载的候选保持稳定，结束后合并处理最新目标。COVER、LOAD、COMMIT、REVEAL 都设有超时失败出口。以上契约已通过控制器12例及相关遮罩/提交专项验证；完整证据与模型边界见交付报告。

## 与 HTML 参考的对应和差异

原 HTML SHA256：`d1171344c3cc83f371fc6875d718ea978a56746945375b3afa2224810e46ea43`。无 Bot 派生版本及8张浏览器参考在 `output/html_fidelity/no_bot/reference`，画面只截取640×480的 `#stage`，不含网页控制台。

- 保留六页原构图、真实产品图、文字和参数。静态正文/图片/背景已烘焙进 UI/PN BMP；本版不分别运动产品图、大字和各组正文，因此不复现 HTML 的分层入场、漂移和错峰浮入。
- Bot 身体、眼睛、角色阴影和专属交互被移除。底部 OSD 卡片仍在原位置/比例：x24、y386、486×72；去掉指向角色的尾角，署名改为“产品导览”，首页字幕改为“欢迎了解安路科技及其四个 FPGA 产品系列。”，保留“静态电流低至5 mA”的已接受文案修正。
- 字幕、打字、页名/页码、进度、缩放观察窗和音频可视化由 RTL OSD 合成，未烘焙进 BMP。产品图和静态字排缩放时，OSD 保持固定尺寸。
- 顶层 `page_event = commit_ack_toggle ^ commit_previous` 对任一视图提交都触发：翻页、单双图、倍率或焦点改变提交后，都会重新启动既有字幕卡换场和33帧打字起始延迟；这与HTML仅改变zoom时不一定重新打字的行为存在差异。背景遮罩在OSD之前，加载期间字幕卡、页码和音频可视化继续运行，仍显示当前已提交状态；新提交到达后与 `active_view` 元数据一起更新。
- 倍率为整数1×/2×/3×，默认2×；以真实源坐标做最近邻采样，六个焦点依次为默认观察区、中心、左、右、上、下。HTML 可连续调节和拖动，本版使用板上按键切换离散倍率/焦点。双图使用两份独立面板拼成的逻辑画布，再按同一观察窗规则取样。
- 继承的是既有逻辑画布采样规则（相同36项原点表、整倍数余数相位和双图配对），其执行从显示期地址映射移到加载期逐行合成。旧packed资源、面板未就绪时的整页回退和384行以下粗采样分支未接入；本套使用完整有效的320×480面板。倍率/焦点改变须重新加载并提交，不能承诺逐帧即时响应。源码证据见 `verify/legacy_spatial_sampling_review.json`。
- 动画为约0.2秒cover（12帧，每帧54像素）→ 遮罩保持并等待加载/写入/提交及完整新front资格帧 → 约0.3秒reveal（18帧，每帧36像素）。postACK的首帧边界只arm，完整资格帧无sticky FIFO fault后下边界揭示；资格和提交等待另计，12帧close/18帧open不变。640×480输出像素时钟25MHz、总时序800×525，实际帧率约59.524Hz；上述时长是按该帧率的近似值，首次显示或关闭动画模式跳过渐变步进，但仍经过遮罩、加载/提交和完整资格帧后，在帧边界直接显示。加载时间取决于真实卡与仲裁，不宣称固定总转场时长。
- 默认轮播5.4秒是 reveal 结束后的完整可见停留时间，加载和转场不计入；HTML 则从切页事件起算并包含转场。因此本版两次切页事件的实际间隔会更长。
- 本版普通BMP主像素保留完整RGB24，不经过前一版面板RGB565/HFXC量化。动态中文字形仍用16×20、2bit覆盖的既有字模；原229字形/9160words保持不变，仅追加新文案字形。安装的Chrome154生成新首页字幕 DOM 基线y415，RTL为保持原生产字幕带归一到y416，存在已记录的1像素差异；旧静态素材来自既有Chrome155导出，字体/排版与当前浏览器参考可能有环境差异。

音频可视化是实际 PCM 峰值的九个时间历史样本，**不是 FFT 频谱**。HTML 未载入WAV时的模拟柱形不能当作真实音频证据。源码中翻页/遮罩不重置WAV，首次画面提交后启动音频，EOF上升沿触发循环重启；重启会重新扫描WAV、清FIFO并重新预填，不能称为gapless连续播放。**这是显著的秒级启动/循环间隙：`audio_media` 从LBA0逐扇区扫描到WAV，未像BMP scanner那样按 `bfSize` 跳过文件。本镜像WAV位于LBA16491，所以首次音频启动及每次EOF重扫至少需要16492个CMD17。按本轮理想事务测试的36613个SD100时钟/CMD17计算，仅扫描下界就是 `16492 × 36613 / 100000000 = 6.03821596秒`，还要加真实卡响应等待、BMP/音频仲裁和重新预填时间。** 这不是整机实测时长，也不包含WAV文件本身的静音段；普通复制后WAV实际LBA变化时必须重新计算。本轮保留该音频扫描架构及媒体布局。暂停、静音、音量由原按键控制。样本通路、HDMI包封装和显示器实际听音属于不同验收层次：本轮完成样本/峰值/摘录循环和BMP并发压力，未完成独立HDMI音频包解码、80秒整曲实时播放或实板听音。

## 按键映射（当前源码）

名称按 `rtl/media_controls.v` 的板上注释：KEY2对应顶层端口 `key1`（next），KEY4对应 `key2`（auto），KEY3对应 `key3`（pause/mute）。输入低有效；去抖20ms，长按阈值1秒。复位进入控制页0、自动轮播开、未暂停、未静音、OSD开、2×、默认焦点、音量8。

| 控制页 | KEY2 短按 | KEY4 短按 |
|---:|---|---|
| 0 播放 | 下一页，松手触发 | 自动轮播开/关，松手触发 |
| 1 亮度 | +16，上限127 | -16，下限-128 |
| 2 对比度 | +1，上限6 | -1，下限0 |
| 3 轮播间隔 | +0.1秒，上限15秒 | -0.1秒，下限1秒 |
| 4 OSD | 开/关 | 开/关 |
| 5 转场模式 | 0→1→2→0 | 0→2→1→0 |
| 6 缩放 | 1×→2×→3×→1×，松手触发 | 反向循环倍率 |
| 7 音量 | +1，上限8 | -1，下限0 |

KEY4长按：控制页0→1→…→7→0，每次长按只前进一页，松手不再产生短按。KEY2在播放页0长按切换单双图，在缩放页6长按循环六个焦点；其余控制页KEY2在按下时调参。播放页0同时按住KEY2+KEY4构成上一页手势，两键都松开后触发一次；该组合不泄漏下一页/自动切换/长按事件。KEY3在所有控制页短按暂停/恢复，长按静音/恢复，长按松手不再触发短按。
